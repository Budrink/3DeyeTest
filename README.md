# LargeFileProcessing

Решение на .NET 8 для генерации и сортировки больших текстовых файлов. Формат строки: `123. Apple`. Сортировка выполняется сначала по тексту (`Ordinal`), затем по числу.

## Проекты

- **FileGenerator** — консольный генератор тестовых файлов заданного размера со случайными числами и текстами.
- **FileProcessor** — внешняя сортировка: разбивает входной файл на порции, сортирует их параллельно и сливает в итоговый файл. Консольная точка входа содержит замеры нескольких конфигураций обработки.
- **FileProcessor.Tests** — тесты на xUnit: проверка парсера строк и сквозной обработки с автоматически созданными временными файлами.
- **FileProcessor.Benchmarks** — отдельные бенчмарки на BenchmarkDotNet: сравнение параллелизма сортировки, параллелизма слияния, количества объединяемых файлов и масштабирования по размеру входа. Результаты экспортируются в CSV. Команды запуска описаны в [README проекта](FileProcessor.Benchmarks/README.md).

В папке [BenchmarkResults](BenchmarkResults/) сохранены графики в PNG:

- [Масштабирование по размеру файла](BenchmarkResults/scaling.png).
- [Сравнение параллелизма и количества файлов на слияние](BenchmarkResults/merge-comparison.png).
- [Обработка больших файлов: 2 и 10 GB](BenchmarkResults/large_files_scaling_test.png) — сравнение времени разбиения и сортировки при разном числе параллельных задач, а также времени слияния при разных сочетаниях параллелизма и количества файлов в группе. Для 2 GB использованы чанки 128 MB, для 10 GB — 256 MB. Лучшие результаты среди проверенных конфигураций:
  - **2 GB:** разбиение и сортировка — **2 мин 43 с** при 6 параллельных задачах; слияние — **2 мин 41 с** при 8 параллельных слияниях по 16 файлов.
  - **10 GB:** разбиение и сортировка — **12 мин 56 с** при 2 параллельных задачах; слияние — **15 мин 54 с** при 8 параллельных слияниях по 8 файлов.
